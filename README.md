# 📧 Email Spam Detection

An Machine Learning based Email Spam Detection system that classifies emails as **Spam** or **Not Spam (Ham)** using the sender email, subject, and email body.

## 📌 Features

- Detects whether an email is Spam or Not Spam
- Uses Machine Learning for classification
- Takes sender email, subject, and email body as input
- Text preprocessing using NLP techniques
- TF-IDF based feature extraction
- Easy-to-use Streamlit web interface
- Displays prediction results

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- TF-IDF
- Machine Learning
- Streamlit
- Joblib
